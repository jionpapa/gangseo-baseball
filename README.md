# 강서리그 야구 (주말경향 전용)

나이스캐치 강서리그 기록을 휴대폰에서 보기 쉽게 정리한 개인용 앱입니다.

- **일정**: 주말경향 경기 날짜·시간·상대팀·구장, 결과
- **우리 팀**: 부 순위, 주말경향 타자·투수 기록
- **상대팀**: 타자 기록(타석 순) → 선수를 누르면 타구 방향 분석·한줄 요약·수비 조언
  투수 기록 → 선수를 누르면 땅볼·뜬공 비율
- **설정**: 분석 범위(작년+올해 합산 / 올해만), 포스트시즌 포함 여부, 리그(부) 선택

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 앱 화면 (GitHub Pages로 배포) |
| `data/manifest.json`, `data/season_<연도>.json` | 기록 데이터 |
| `scraper/scrape.js` | 나이스캐치 페이지에서 원자료를 모으는 스크립트 (Claude 내장 브라우저에서 실행) |
| `tools/preprocess.py` | 원자료 → 앱 데이터 변환 (타석 코드, 투수별 땅볼·뜬공 배정) |
| `android/` | APK(웹뷰 껍데기). 앱 화면은 GitHub Pages에서 받아오므로 데이터 갱신 때 재설치 불필요 |

## 데이터 갱신 순서

1. 내장 브라우저에서 nicecatch.kr 강서리그 페이지를 열고 `scraper/scrape.js`를 실행
2. `await GS.setYear(연도)` → `await GS.list()` → `GS.boxes(400)` (끝날 때까지) → `GS.save()`
3. 다운로드 폴더의 `gangseo_<연도>.json`을 가져와 `python3 tools/preprocess.py gangseo_<연도>.json data/season_<연도>.json`
4. `data/manifest.json`의 해당 시즌 `version`과 `updated`를 바꾸고 커밋

## 기록 해석 메모

- 타구 방향은 기록지 표기(좌·좌중·중·우중·우, 내야 포지션)를 그대로 셉니다. '좌선'은 좌, '우선'은 우.
- 내야 땅볼 = 땅볼 아웃·진루타·병살타. 내야안타·실책은 땅볼 집계에서 제외.
- 투수 땅볼·뜬공: 기록지에 타석별 상대 투수가 없어, 이닝별 타순 재구성 + 투수별 상대 타자 수로 배정한 추정치. 외야 안타는 타구 종류를 알 수 없어 비율에서 제외.
- 이름 대신 긴 숫자가 등록된 선수는 '이름미표기'로 표시합니다.
